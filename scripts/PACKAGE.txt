kapila-maker
https://github.com/radomd92/kapila-burner

Every platform archive contains both interfaces:
  kapila-maker[.exe]       GTK desktop application
  kapila-maker-web[.exe]   Local web server with embedded browser interface

Malagasy is the default. Switch with the language selector or -lang en / -lang fr.

Windows x86-64:
- Install using kapila-maker-windows-amd64-setup.exe (per-user, no admin needed),
  or extract the entire ZIP and run kapila-maker.exe / launch-gtk.cmd.
- GTK, all required DLLs/data, FFmpeg, FFprobe, VCDImager, dvda-author and genuine
  mkisofs are included. No MSYS2 or Go required; see below for DVD-Video.
- Do not move a single EXE away from its bundled runtime directory.

macOS 15 or newer, Intel x86-64:
- Open the DMG and copy kapila-maker.app to Applications, or extract the archive.
- GTK and the five bundled utilities and their non-system libraries are included.
  No Homebrew, Go or FFmpeg installation is required; see below for DVD-Video.
- The app is ad-hoc signed, NOT Developer ID signed or notarized. Follow normal
  Gatekeeper/organization policy; do not disable system-wide security protections.
- No Apple Silicon native build is claimed.

Linux x86-64 and ARM64:
- The release is built on Ubuntu 22.04 and requires a compatible glibc system.
- Extract the entire archive and run ./kapila-maker or ./kapila-maker-web.
  Keep tools/ and BUILD-UTILITIES.txt beside the executables.
- FFmpeg, FFprobe, VCDImager, dvda-author and mkisofs are included.
  No separate tool installation or PATH setup is required for DVD-Audio or VCD images.
- The desktop app uses system GTK 3; VCDImager uses system shared libraries.
  On Ubuntu 22.04: libgtk-3-0 (desktop), libcdio19 libiso9660-11 libpopt0 (VCD).
  On Ubuntu 24.04 / Linux Mint 22: libgtk-3-0t64 (desktop),
  libcdio19t64 libiso9660-11t64 libpopt0 (VCD).
- Install cdrdao separately only if you want physical VCD burning.
- On Raspberry Pi, use the ARM64 archive with 64-bit Raspberry Pi OS
  (Bookworm or newer). The Bookworm runtime packages match the Ubuntu 22.04
  names above. On Raspberry Pi OS Trixie, use libgtk-3-0t64 for GTK. For VCD,
  install the system vcdimager package and launch with VCDIMAGER=/usr/bin/vcdimager
  because the bundled executable uses the older library ABI. No 32-bit Pi build.

Linux RISC-V (riscv64, not for Raspberry Pi):
- Built for Debian 13 (Trixie) or a compatible distribution; tools are not bundled.
- Install libgtk-3-0t64 for GTK and ffmpeg, vcdimager, dvdauthor, genisoimage
  for VCD and DVD-Video authoring. DVD-Audio requires separate compatible
  builds of dvda-author and, for ISOs, mkisofs with -dvd-audio support.
- Launch with -root and -output, or use the working-directory defaults of
  .. and ./output. Utilities are resolved from PATH or explicit overrides.

Bundles with utilities find them relative to their executable. Defaults for
those bundles: user Music library and kapila-maker/output in the per-user cache.
Pass -root /path/to/media and -output /path/to/output to override them.
In GTK, open a project and click Scan Folder to scan the selected directory.
External Tools shows dependency status and opens paths and diagnostics.

For the web interface, run kapila-maker-web[.exe] -root /path/to/media, then open
the loopback URL printed in the terminal, normally http://127.0.0.1:8787.
Keep the terminal open. Do not expose the service to a network.

DVD-Video (ISO only):
- Install dvdauthor separately (not the bundled DVD-Audio tool dvda-author).
  Put it on PATH or set DVDAUTHOR to its absolute executable path.
- The bundled mkisofs supports -dvd-video. Optionally set DVD_VIDEO_MKISOFS
  to a compatible executable, such as genisoimage. Do not use genisoimage
  for DVD-Audio, which requires mkisofs with genuine -dvd-audio support.
- Choose PAL or NTSC and DVD-5 or DVD-9. Add up to 99 video clips to one
  group in playback order. Clips autoplay in order with chapters and no menus.
- Two-pass adaptive MPEG-2 encoding uses Half-D1 when needed. Projects that
  cannot fit without going below the quality floor are rejected. The first
  audio stream becomes stereo AC-3; clips without audio get silence.
- No physical DVD burning or DVD-9 layer-break authoring.

Only Linux supports optional, explicitly confirmed physical VCD writing with
cdrdao. Use external recording software for DVD ISOs and for VCD BIN/CUE
images on Windows/macOS. No CI job burns a disc.

For bundles with utilities, corresponding utility/runtime sources and patches
are published in matching -sources.tar.gz archives. Keep license notices intact.
SHA256SUMS covers installers, portable distributions and corresponding sources.
Read BUILD-UTILITIES.txt and platform runtime manifests or Linux linkage reports
for build and shared library details.
