kapila-maker
https://github.com/radomd92/kapila-burner

Every platform archive contains both interfaces:
  kapila-maker[.exe]       GTK desktop application
  kapila-maker-web[.exe]   Local web server with embedded browser interface

Malagasy is the default. Switch with the language selector or -lang en / -lang fr.

Windows x86-64:
- Install using kapila-maker-windows-amd64-setup.exe (per-user, no admin needed),
  or extract the entire ZIP and run kapila-maker.exe / launch-gtk.cmd.
- GTK, all required DLLs/data, FFmpeg, FFprobe, VCDImager, dvda-author and genuine
  DVD-Audio mkisofs are included. No MSYS2, Go, or separate utility installs needed.
- Do not move a single EXE away from its bundled runtime directory.

macOS 15 or newer, Intel x86-64:
- Open the DMG and copy kapila-maker.app to Applications, or extract the archive.
- GTK and all five authoring utilities and their non-system libraries are included.
  No Homebrew, Go, FFmpeg installation or PATH setup is required on the user's Mac.
- The app is ad-hoc signed, NOT Developer ID signed or notarized. Follow normal
  Gatekeeper/organization policy; do not disable system-wide security protections.
- No Apple Silicon native build is claimed.

Linux x86-64:
- GTK 3 and the external authoring programs must still be installed separately.
  See the repository's dependency instructions. This change bundles Windows/macOS.

Bundled Windows/macOS apps find tools relative to their executable, not the working
directory. Defaults: user Music library and kapila-maker/output in the per-user cache.
Pass -root /path/to/media and -output /path/to/output to override them.

For the web interface, run kapila-maker-web[.exe] -root /path/to/media, then open
the loopback URL printed in the terminal, normally http://127.0.0.1:8787.
Keep the terminal open. Do not expose the service to a network.

Only Linux supports optional, explicitly confirmed physical VCD writing with
cdrdao. Windows/macOS create complete DVD-Audio ISO and VCD BIN/CUE images;
write those images using external recording software. No CI job burns a disc.

Corresponding utility/runtime sources and patches are published beside these
downloads in the matching -sources.tar.gz archive. Keep license notices intact.
SHA256SUMS covers installers, portable distributions and corresponding sources.
Read BUILD-UTILITIES.txt and platform runtime manifests for exact build versions.
